Refactor: extract CSS/JS, sanitize SVG inputs, accessibility & performance

This PR moves inline CSS and JS into separated files, wires a sanitizer for SVG inputs (using DOMPurify when available), and starts accessibility and performance improvements.

Changes:
- styles.css: extracted CSS variables + minimal rules
- js/utils.js: safe localStorage, debounce, scheduleRender, sanitizeSvg wrapper
- js/main.js: bootstrapper & helper toasts
- js/app.js: incremental port of inline app wiring (non-destructive)
- index.html: now loads styles.css, DOMPurify CDN, and the JS modules

Testing checklist:
- Open the app in a browser and verify UI loads
- Import an SVG via "Import SVG File" and ensure sanitized content appears
- Move sliders / change settings; canvas placeholder redraws

Notes:
- Work is intentionally incremental; commits are kept separate for review. Please review carefully before merging.
