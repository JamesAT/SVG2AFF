How to Import

Basic Steps

  1. Copy or import your .svg file or path string.
  2. Adjust scale, position, or complexity, then click Copy Output.

Method 1: ArcCreate Text Tab

  • Open ArcCreate and load your chart project.
  • Switch to the raw text editing tab ( < > ).
  • Paste the copied lines directly into the text editor.
Note: Direct text edits inside ArcCreate cannot be undone.
Tip: Create a dedicated timing group first, scroll to the bottom, and paste the code there to keep things organized.

Method 2: Direct .aff File Editing

  • Open your target .aff chart file in any text editor.
  • Paste the generated arc lines into the file where needed.
  • Save the file and reload the chart in your chart editor.
