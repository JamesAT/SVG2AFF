How to Import

BASIC STEPS

  1. Paste SVG path data, convert text, pick a shape preset, or import .svg files (Single or Layers mode).
  2. Adjust scale, position, rotation, or complexity, then click Copy Output.

METHOD 1: ARCCREATE TEXT TAB

  • Open ArcCreate and load your chart project.
  • Switch to the raw text editing tab ( < > ).
  • Paste the copied lines directly into the text editor.
Note: Direct text edits inside ArcCreate cannot be undone within the editor.
Tip: Create a dedicated timing group first, scroll to the bottom, and paste the code there to keep your chart organized.

METHOD 2: DIRECT .AFF FILE EDITING

  • Open your target .aff chart file in any text editor.
  • Paste the generated arc lines into the file where needed.
  • Save the file and reload the chart in your chart editor.
About & Info

SVG to .aff Converter

A high-performance standalone web utility designed to sample vector SVG paths and convert them into Arcaea chart format (.aff) in real time with optional Photoshop-style multi-layer editing.

  • SVG DOM Path Sampling: Standard W3C SVG 1.1 Specification (SVGPathElement.getPointAtLength() API).
